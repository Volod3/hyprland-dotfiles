# Fastfetch-логотип: як замінити картинку

Тека `~/.config/fastfetch/`:

| Файл | Призначення |
|---|---|
| `config.jsonc` | основа конфігу (модулі, рамки, кольори) |
| `mkcfg.py` | підбирає розмір картинки під розмір вікна і додає відступ у пів рядка |
| `my_image_fixed.png` | **картинка, яка показується** |
| `my_image.jpg` | оригінал-заготовка (скриптом не використовується) |
| `README.md` | цей файл |

## Вимоги до картинки

- **Ім'я:** `my_image_fixed.png`, у тій самій теці, де лежить `mkcfg.py`.
- **Формат:** PNG (RGB або RGBA).
- **Пропорції:** квадрат **1:1**. Зараз 1280×1280 px; підійде будь-який квадрат від 512×512.
- **Прозорі поля і рамки додавати НЕ треба.** Скрипт сам додає пів рядка зверху і знизу, щоб картинка стояла рівно з першим рядком тексту.
- Не квадратна картинка буде розтягнута, тому спочатку обріж її до квадрата.

Підготувати будь-яку картинку (обрізає по центру до квадрата, 1280×1280, зберігає як PNG):

```bash
python3 -c "from PIL import Image; import sys; im=Image.open(sys.argv[1]).convert('RGB'); s=min(im.size); l=(im.width-s)//2; t=(im.height-s)//2; im.crop((l,t,l+s,t+s)).resize((1280,1280), Image.LANCZOS).save(sys.argv[2])" ВХІДНА.jpg ~/.config/fastfetch/my_image_fixed.png
```

Кеш (`~/.cache/ff-logo-h*.png`) оновлюється сам, коли файл картинки новіший за нього. За потреби можна видалити: `rm ~/.cache/ff-logo-h*.png`.

## Який розмір матиме картинка

Розмір росте разом із шириною вікна (колонки = `tput cols`):

| Колонок | Картинка (колонок × рядків) |
|---|---|
| менше 83 | немає |
| 83 | 18 × 9 |
| 85 | 20 × 10 |
| 86 | 21 × 11 |
| 90 | 25 × 13 |
| 94 | 29 × 15 |
| 96 | 31 × 16 |
| 97 і більше | 32 × 16 (максимум) |

Якщо вікно нижче 22 рядків, зникає рядок із кольоровими крапками, а висота картинки обмежується 15 рядками.

Формула: ширина картинки = колонки − 65 (63 колонки займають рамки з текстом, 1 відступ, 1 запас), висота = половина ширини.

## Налаштування в `mkcfg.py`

- `MIN_W` найменша ширина картинки (з цього розміру вона з'являється).
- `MAX_W`, `MAX_H` найбільший розмір (зараз 32 × 16).
- `BOX` ширина рамок із текстом (63), змінюй, якщо змінюєш їх у `config.jsonc`.
- `PAD` відступ праворуч від картинки.

## Запуск

- `ff` або `fastfetch` без аргументів: показує fastfetch під поточний розмір вікна.
- `cf` очищає екран і перемальовує fastfetch.
- При старті терміналу і при зміні розміру вікна fastfetch перемальовується сам (`~/.config/fish/conf.d/ff-resize.fish`). Після `Ctrl+L` або «Очистити термінал» у меню перемальовка вимикається, лишається тільки промпт.
