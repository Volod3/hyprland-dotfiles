# ⌨️ Комбінації та можливості — Hyprland «Азур»

Оновлено: 13.11.2026 · Усі бінди живуть у `~/.config/hypr/hyprland.lua`
Перегляд/пошук по біндах у GUI: **Super + Alt + S**

## Застосунки та меню
| Комбінація | Що робить |
|---|---|
| **Meta (утримати ~0.3 с)** | Лаунчер застосунків (іконки + пошук) |
| **Super + Space** / **Super + R** | Той самий лаунчер |
| **Super + Q** | Термінал kitty |
| **Super + D** | Dolphin |
| **Super + B** | Google Chrome |
| **Super + T** | Telegram |
| **Super + W** | WhatsApp (Whatsie) |
| **Super + Alt + V** | Панель керування: звук, мікрофон, яскравість, BT/DND/ігровий режим |
| **Super + Alt + S** | Налаштування Hyprland (клавіші, оформлення, теми) |
| **Super + S** | pavucontrol (повний мікшер) |

## Теми та шпалери
| Комбінація | Що робить |
|---|---|
| **Pause / Break** | Меню тем (на зайнятому столі стрибає на вільний; повторне натискання — закриває й повертає) |
| **Super + Alt + B** | Те саме меню тем |
| **Super + Alt + T** | Швидко перемкнути тему туди-сюди |
| **Super + Alt + G** | Ігровий режим уручну (авто — у fullscreen-іграх) |

## Скріншоти
| Комбінація | Що робить |
|---|---|
| **Print** | Скріншот усього екрана → `~/Картинки/Знімки вікон` + буфер |
| **Shift + Print** / **Super + Shift + S** | Скріншот області (виділення мишею) |

## Вікна та столи
| Комбінація | Що робить |
|---|---|
| **Super + F** | «На весь екран» із панеллю (maximize) |
| **F11** | Справжній fullscreen (панель ховається) |
| **Super + C** | Закрити вікно |
| **Super + V** | Плаваюче вікно |
| **Super + P** | Псевдотайлінг |
| **Super + J** | Dwindle: split/unsplit |
| **Super + 1…0** | Перейти на стіл 1–10 |
| **Super + Shift + 1…0** | Перекинути вікно на стіл 1–10 |
| **Super + A** | Спеціальний (magic) стіл |
| **Super + Shift + A** | Перекинути вікно на magic-стіл |
| **Super + ←/→/↑/↓** | Фокус між вікнами |
| **Super + Shift + ←/→/↑/↓** | Змінити розмір вікна |
| **Super + ЛКМ / ПКМ** | Перетягнути / змінити розмір |
| **Super + колесо** | Наступний / попередній стіл |
| **3 пальці ←/→** | Свайп між столами |
| **Super + M** | Вихід із сесії |

## Медіа та система
| Комбінація | Що робить |
|---|---|
| **Fn-клавіші гучності / яскравості** | Системні (wpctl, brightnessctl) |
| **XF86AudioNext / Play / Prev** | Керування плеєром (playerctl) |

## Що де налаштувати
- **Теми** — `~/.config/theme-switch/themes/*/`, `theme-switch apply 1|2`, стан у `state/current`.
- **Паралакс, Mimi, cava** — `~/.config/wallpapers_QS/<тема>/settings.json` (після змін — `theme-switch apply <тема>`, бо атомарний запис рве watch).
- **Ігровий режим** — `game-mode on|off|toggle|status`; автодетект — `game-watch`; статичні картинки — `theme-switch/static/`.
- **Панель/сповіщення/термінал/лаунчер** — палітри в `themes/*/` (waybar.css.head, swaync.css.head, wofi.css, kitty.colors).
- **Бінди** — `~/.config/hypr/hyprland.lua`; живий перегляд — Super+Alt+S.
